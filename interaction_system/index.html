2. Technical Architecture

  • Interface-Driven (IInteractableInterface): Decouples the character from interacting actors, eliminating hard casting.
  • Raycast Priority System: Performs dynamic line-traces/sphere-sweeps to select the optimal target when multiple interactable actors overlap.
  • UI Binding via Delegates: Fires dynamic broadcast delegates to update HUD prompts without polling on Tick.
  • Edge-Case Handling: Smoothly handles dynamic actor destruction, range limits, and interrupted channel interactions.
