2. Technical Architecture

  • Interface-Driven Architecture (IInteractionInterface): Decouples interaction logic from specific actor classes, executing interactions cleanly without hard casting.
  • Dynamic Trace Sweeping: Utilizes line-traces and sphere-sweeps to continuously evaluate interactable targets and manage actor highlight states in real time.
  • Direct HUD & Hold-Press Integration: Communicates target state directly to the HUD class to render interaction widgets and drive timed hold-press progress bars.
  • Edge-Case & Interruption Handling: Manages state cleanup, timer cancellations for early input releases, and out-of-range target resets to prevent orphaned UI prompts.
