UE5 C++ Inventory Save System

Engine Version: Unreal Engine 5.6 | Language: C++

Architecture Context & Baseline

The Inventory Save System isolates runtime UObject logic from disk storage using lightweight FInv_ItemManifest value structs. Instead of serializing heavy object instances, it captures grid dimensions, anchor slot indices, stack counts, and equipment slots into compact binary data structures.

1. Gameplay Video Showcase

2. Key Technical Features

  • Manifest Serialization Pattern: Uses lightweight FInv_ItemManifest value structs to preserve item definitions, stack counts, and slot indices without serializing entire C++ UObject instances.
  • Multi-Grid Storage Mapping: Organizes save data into a TMap<int32, FInventorySaveData> structure, mapping distinct sub-grids (e.g., Equippables vs. Consumables) alongside active equipment slots.
  • Anchor-Slot Deduplication: Prevents data duplication for multi-tile spatial items by filtering save sweeps to only capture upper-left anchor coordinates (UpperLeftIndex).
  • State Reconstruction Pipeline: Restores dimensions, reconstructs runtime grid bounds, and instantiates item instances using factory manifests to safely restore dynamic UI listeners and server state.
  • Code reusability: Reused most logic and code from the original inventory system.

//InventoryGrid.cpp
FInventorySaveData UInv_InventoryGrid::GetInventorySaveData() const
{
	FInventorySaveData OutData;

	//Store the size
	OutData.InventorySize = FIntPoint(Rows, Columns);

	for (const UInv_GridSlot* GridSlot : GridSlots)
	{
		//Only save anchor (upper-left) slots to avoid duplicating multi-tile
		if (!GridSlot->IsAvailable()
			&& GridSlot->GetInventoryItem().IsValid()
			&& GridSlot->GetUpperLeftIndex() == GridSlot->GetTileIndex())
		{
			FInv_SavedItemEntry Entry;
			Entry.UpperLeftIndex = GridSlot->GetTileIndex();
			Entry.StackCount = GridSlot->GetStackCount();
			Entry.ItemManifest = GridSlot->GetInventoryItem()->GetItemManifest();
			OutData.SavedItems.Add(Entry);
		}
	}

	return OutData;
}

void UInv_InventoryGrid::LoadInventory(const FInventorySaveData& InSaveData)
{
	//Restore inventory size
	Rows = InSaveData.InventorySize.X;
	Columns = InSaveData.InventorySize.Y;
	GridSlots.Empty();
	ConstructGrid();

	UObject* Outer = GetOwningPlayer();

	for (const FInv_SavedItemEntry& Entry : InSaveData.SavedItems)
	{
		if (!GridSlots.IsValidIndex(Entry.UpperLeftIndex))
		{
			UE_LOG(LogInventoryPlugin, Warning, TEXT("LoadInventory: invalid index %d, skipping"),
				Entry.UpperLeftIndex);
			continue;
		}

		FInv_ItemManifest ManifestCopy = Entry.ItemManifest;
		UInv_InventoryItem* NewItem = ManifestCopy.Manifest(Outer);
		if (!NewItem) continue;

		NewItem->SetTotalStackCount(Entry.StackCount);
		AddItemAtIndex(NewItem, Entry.UpperLeftIndex, NewItem->IsStackable(), Entry.StackCount);
		UpdateGridSlots(NewItem, Entry.UpperLeftIndex, NewItem->IsStackable(), Entry.StackCount);

		InventoryComponent->GetInventoryList().AddEntry(NewItem);
	}
}
