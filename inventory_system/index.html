UE5 C++ Grid & Spatial Inventory System

Engine Version: Unreal Engine 5.6 | Language: C++ / Blueprints

Architecture Baseline & Extensions

This system was built upon Stephen Ulibarri's C++ Inventory Architecture baseline, which was then extended with custom feature additions including item rotation, dynamic grid expansion, and persistent state saving.

2. Technical Features & Custom Work

  • Course Baseline: 2D spatial grid, drag-and-drop item management, and item stack splitting/combining.
  • Custom Extension — Item Rotation (90°): Implemented dynamic matrix rotation in C++ to allow rectangular items to rotate and re-validate bounding slots before placement.
  • Custom Extension — Dynamic Grid Expansion: Developed runtime grid resizing logic driven by backpack upgrades and character traits.
  • Custom Extension — Save System Integration: Serialized grid item coordinates, stack quantities, and custom item struct parameters directly into the USaveGame architecture. More info here.

Call Rotation in the InventoryGrid

//InventoryGrid.cpp
void UInv_InventoryGrid::TryRotateHoverItem()
{
	if (HoverItem && HoverItem->GetInventoryItem())
	{
		UInv_InventoryItem* Item = HoverItem->GetInventoryItem();
		if (const FInv_GridFragment* GridFragment = GetFragment(HoverItem->GetInventoryItem(), FragmentTags::GridFragment))
		{
			if (!GridFragment->CanBeRotated()) return;
			GridFragment->ToggleRotation();
			UE_LOG(LogInventoryPlugin, Log, TEXT("UInv_InventoryGrid::TryRotateHoverItem - Rotate hover item"));

			AssignHoverItem(Item); //refresh visual
		}
	}
}

Handle Rotation offset

//InventoryGrid.cpp
FVector2D UInv_InventoryGrid::GetRotationOffset(const FInv_GridFragment* GridFragment) const
{
	if (!GridFragment->IsRotated())
	{
		return FVector2D::ZeroVector;
	}

	FIntPoint Size = GridFragment->GetGridSize();
	/**
	 * MATH EXPLANATION:
	 * When rotating a non-square item (e.g., 2x1) around center (0.5, 0.5),
	 * the new visual "top-left" is shifted. To snap it back to the grid:
	 * Offset = (Width - Height) * TileSize * 0.5
	 */
	float OffsetX = (Size.Y - Size.X) * TileSize * 0.5f;
	float OffsetY = (Size.X - Size.Y) * TileSize * 0.5f;

	return FVector2D(OffsetX, OffsetY);
}
