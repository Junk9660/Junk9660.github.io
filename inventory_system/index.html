UE5 C++ Grid & Spatial Inventory System

Engine Version: Unreal Engine 5.6 | Language: C++ / Blueprints

Architecture Baseline & Extensions

This system was built upon Stephen Ulibarri's C++ Inventory Architecture baseline, which was then extended with custom feature additions including item rotation, dynamic grid expansion, and persistent state saving.

2. Technical Features & Custom Work

  • Course Baseline: 2D spatial grid, drag-and-drop item management, and item stack splitting/combining.
  • Custom Extension — Item Rotation (90°): Implemented dynamic matrix rotation in C++ to allow rectangular items to rotate and re-validate bounding slots before placement.
  • Custom Extension — Dynamic Grid Expansion: Developed runtime grid resizing logic driven by backpack upgrades and character traits.
  • Custom Extension — Save System Integration: Serialized grid item coordinates, stack quantities, and custom item struct parameters directly into the USaveGame architecture. More info here.
