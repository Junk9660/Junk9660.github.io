UE5 C++ Event-Driven Quest System

Engine Version: Unreal Engine 5.6 | Language: C++ / Blueprints

Architecture Context & Baseline

Event-Driven quest system to track quests and player interaction, integrating full UI for player information.

2. Key Technical Features

  • Event-Driven UQuestSubsystem: Use of a Subsystem as an event bus to handle quest updates and UI updates.
  • Easy Integration: Use of Data Asset for visual quest creation and exposed variables for quest update.
  • Modular System: Implement a QuestComponent for modular integration on any actor and trigger.
  • UI Delegates: Execute delegate to update the UI based on active quest, providing real time information.

3. Technical "Deep-Dives"

Load the quests from the DataAsset by using a QuestConfig actor in the level

//Quest Subsystem.cpp
void UQuestSubsystem::LoadQuestsFromDataAsset()
{
	if (!Quests.IsEmpty()) return;
	UWorld* World = GetWorld();
	if (!World)
	{
		UE_LOG(LogQuestSystem, Warning, TEXT("QuestSubsystem: No valid world found to find QuestConfigActor."));
		return;
	}
	MapName = World->GetMapName();
	MapName = World->RemovePIEPrefix(MapName);
	UE_LOG(LogQuestSystem, Log, TEXT("QuestSubsystem: MapName %s"),
		*MapName);
	UE_LOG(LogQuestSystem, Log, TEXT("QuestSubsystem: World valid"));
	for (TActorIterator It(World); It; ++It)
	{
		UE_LOG(LogQuestSystem, Log, TEXT("QuestSubsystem: ConfigActor Iterate"));
		AQuestConfigActor* ConfigActor = *It;

		if (ConfigActor && !ConfigActor->QuestDataAsset.IsNull())
		{
			UE_LOG(LogQuestSystem, Log, TEXT("QuestSubsystem: Found QuestConfigActor"));
			LoadedQuestDataAsset = ConfigActor->QuestDataAsset.LoadSynchronous();
			if (LoadedQuestDataAsset)
			{
				UE_LOG(LogQuestSystem, Log, TEXT("QuestSubsystem: QuestDataAsset is loaded"));
			}
			break;
		}
	}
	if (!LoadedQuestDataAsset)
	{
		UE_LOG(LogQuestSystem, Warning, TEXT("QuestSubsystem: Failed to load QuestDataAsset"));
		return;
	}

	//To see if starting only a specific quest
	for (const FQuestData& QuestInfo : LoadedQuestDataAsset->Quests)
	{
		if (QuestInfo.AssociatedMap.Equals(MapName, ESearchCase::IgnoreCase) && QuestInfo.bIsMainQuest)
		{
			UQuestObject* NewQuest = NewObject(this);
			NewQuest->InitializeFromData(QuestInfo);
			Quests.Add(NewQuest);
			OnQuestStarted.Broadcast(NewQuest);
		}
	}
	UE_LOG(LogQuestSystem, Log, TEXT("QuestSubsystem: Loaded %d quests from data asset"),
		Quests.Num());
}
