4. Technical Deep-Dives

CommonUI Stack & Data Table Action Binding

Utilizes UCommonActivatableWidget to manage UI focus and input handling. Action rows are bound dynamically upon widget activation to handle controller/keyboard inputs cleanly without polling. 

// Inv_LootDisplay.cpp
void UInv_LootDisplay::NativeOnActivated()
{
    Super::NativeOnActivated();
    RefreshLootUI();

    FBindUIActionArgs BindArgs(TakeAllActionRow, FSimpleDelegate::CreateUObject(this, &UInv_LootDisplay::TakeAll));
    BindArgs.bDisplayInActionBar = true;
    TakeAllBindingHandle = RegisterUIActionBinding(BindArgs);
}

Container Transaction Pipeline

Executes non-destructive item transfers using inventory space sweeps (TryAddItemManifest). Based on stack remainders, the local container updates or clears its local manifests while notifying the component to replicate updated states. 

// Inv_LootDisplay.cpp
FInv_SlotAvailabilityResult Result = IC->TryAddItemManifest(Item);

if (Result.Remainder == 0)
{
    LootSlot->DisableSlot();
    OnItemAdded.Broadcast(TileIndex, Result.Remainder);
}
else
{
    if (FInv_StackableFragment* Stackable = Item.GetFragmentOfTypeMutable())
    {
        Stackable->SetStackCount(Result.Remainder);
    }
    OnItemAdded.Broadcast(TileIndex, Result.Remainder);
}
