2. Technical Architecture

  • Interface-Driven Persistence (ISaveInterface): Decouples save logic from world actors, allowing any actor to serialize its state without hard dependencies or direct class casting.
  • Modular System Structs & Proxy Archives: Encapsulates player, quest, and inventory states into dedicated structs, using FObjectAndNameAsStringProxyArchive to serialize only variables tagged with UPROPERTY(SaveGame) into compact byte arrays.
  • Automated World State & Destruction Tracking: Listens for actor destruction events via a central UGameInstanceSubsystem to log unique FGuid entries into a DestroyedActors registry, ensuring level-placed items and objects stay deleted upon reloading.
  • Asynchronous Disk I/O & UI Delegates: Executes non-blocking async save/load requests via a custom UGameInstanceSubsystem to prevent frame hitches, firing dynamic delegates to notify UI widgets upon completion.

Gameplay Tag Filtering — Check player state to allow saving

Prevents saving if the player is in defined states, by quering FGameplayTag (player jumping, in combat, ...)

// PlayerController On Jump
ActiveTags.AddTag(SaveTags::SaveBlockingJumping);
//SaveSubsystem.cpp
USaveSubsystem::USaveSubsystem()
{
	BlockingSaveTag.AddTag(SaveTags::SaveBlockingJumping);
	BlockingSaveTag.AddTag(SaveTags::SaveBlockingCombat);
	BlockingSaveTag.AddTag(SaveTags::SaveBlockingSaving);
}
bool USaveSubsystem::CannotSave() const
{
	if (SavingTag.MatchesTagExact(SaveTags::SaveBlockingSaving))
	{
		UE_LOG(LogSaveInterface, Warning, TEXT("CanSave blocking saving"));
		return false;
	}
	APlayerController* PC = UGameplayStatics::GetPlayerController(GetWorld(), 0);
	if (ISaveInterface::Execute_HasAnyMatchingGameplayTags(PC, BlockingSaveTag))
	{
		UE_LOG(LogSaveInterface, Log, TEXT("CanSave has tag"));
		return true;
	}
	return false;
}
Auto save and Save Component — Async background saving via world actors

Integrates seamless checkpoint saves on any actor, by using a SaveComponent. The SaveSubsystem processes these auto-save calls asynchronously, while preventing multiple auto save in a short interval.

//SaveComponent.h
UPROPERTY()
	float LastAutoSaveTime = -BIG_NUMBER;

	UPROPERTY(EditAnywhere, Category = "AutoSave")
	float AutoSaveInterval = 30.f;

//SaveComponent.cpp
void USaveComponent::TriggerAutoSave()
{
	UWorld* World = GetWorld();
	if (!World) return;

	const float CurrentTime = World->GetTimeSeconds();
	if (CurrentTime - LastAutoSaveTime < AutoSaveInterval)
	{
		return;// last auto save from this actor was too soon
	}
	LastAutoSaveTime = CurrentTime;

	UGameInstance* GI = World->GetGameInstance();
	if (!GI) return;

	SaveSubsystem = GI->GetSubsystem();
	if (SaveSubsystem)
	{
		SaveSubsystem->SaveWorldAsync("", ESaveType::AutoSave);
	}
}
