2. Technical Architecture

  • Component-Based Persistence: Built using a reusable USaveableComponent pattern, allowing any world actor to become persistent without hardcoding write routines.
  • Struct Serialization: Encapsulates transform data, actor states, dynamic arrays, and variables into clean C++ structs for efficient I/O.
  • Asynchronous Processing: Utilizes non-blocking async save/load routines to prevent frame hangups during heavy disk writes.
  • State Restoration Edge Cases: Properly reinstantiates dynamic actors destroyed or spawned during play sessions upon loading.

Selective Filtering via GameplayTags

Optimizes serialization sweeps by checking FGameplayTag containers, skipping transient actors during save sweeps. 

// SaveSubsystem.cpp
// Check if the actor should be ignored during save serialization
if (Actor->Implements())
{
    const FGameplayTagContainer TagContainer = ISaveableInterface::Execute_GetSaveStateTags(Actor);
    if (TagContainer.HasTagExact(FGameplayTag::RequestGameplayTag(FName("Save.Ignore"))))
    {
        return; // Skip transient actor
    }
}
