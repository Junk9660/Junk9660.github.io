Engine Version: Unreal Engine 5.8 | Language: C++ / BP

Architecture Context & Baseline

User interface bound to the Subsystem delegate to provide to the player the possibility to save and load his progression

2. Key Technical Features

  • Subsystem-Driven Async I/O: Leverages UGameInstanceSubsystem to execute non-blocking disk reads and writes via dynamic delegates (FAsyncSaveGameToSlotDelegate), preventing main-thread hitches during heavy file transfers.
  • Modular Struct Container Architecture: Encapsulates player state, actor states, inventory, quest progress, and world flags into domain-specific structs inside UMySaveGame, maintaining a clean data hierarchy.
  • Automated Destruction Tracking: Registers actor destructions to a persistent DestroyedActorGuids array within FWorldStateSaveData, ensuring destroyed world actors are purged during actor restoration.
  • Proxy Archive Serialization: Populates the SerializedData byte array within FActorSaveData using FObjectAndNameAsStringProxyArchive, serializing only properties marked with UPROPERTY(SaveGame).

Interface Driven — Decoupled system with interface

Use of Interface to retrieve and set back data without hard casting.


FActorSaveData ABaseActor::GetSaveData_Implementation()
{
	FActorSaveData ActorSaveData;
	ActorSaveData.Transform = GetTransform();
	ActorSaveData.ActorClass = this->GetClass();
	ActorSaveData.bIsRuntimeSpawned = bIsSpawnedAtRunTime;
	UInv_LootComponent* LootComp = FindComponentByClass();
	if (LootComp)
	{
		ActorSaveData.FInv_LootData = LootComp->GetInventoryList();
	}

	return ActorSaveData;
}
void ABaseActor::OnLoadGame_Implementation(const UMySaveGame* SaveDataObject)
{
	UInv_LootComponent* LootComp = FindComponentByClass();
	if (LootComp)
	{
		FActorSaveData ActorSaveData = SaveDataObject->SavedActorMap.FindRef(SaveActorID);
		LootComp->SetInventoryList(ActorSaveData.FInv_LootData);
	}
}
Destroyed Actors Tracking — Prevent loading destroyed actors

SaveSubsystem tracks destroyed actors within an TArray DestroyedActorGuids;.

//SaveSusbystem.cpp
//Called by Actor's EndPlay()
void USaveSubsystem::RegisterDestroyedActor(const FGuid& ActorGuid)
{
	if (!CurrentSave) return;
	CurrentSave->WorldState.DestroyedActorGuids.AddUnique(ActorGuid);
	UE_LOG(LogSaveInterface, Warning, TEXT("Actor with following ID %s has been destroyed"), *ActorGuid.ToString())
}
